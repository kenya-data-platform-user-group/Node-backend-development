# Node Backend Development

A practical Node.js backend learning repo built with NestJS, PostgreSQL, and Drizzle ORM. It walks from project setup and CRUD design to clean architecture and microservices with Redis, RabbitMQ, and gRPC.

## What is inside

- `1.project-setup` - foundational NestJS API setup with Docker, PostgreSQL, and Drizzle
- `2.CRUD & DB Modelling` - CRUD patterns, schema design, validation, and database workflows
- `3.Clean-Architecture` - the same backend organized with clean architecture principles
- `4. Microservices Pub-Sub - Redis` - event-driven services using Redis pub/sub
- `5. Microservices Message Broker - RabbitMQ` - broker-based messaging with RabbitMQ
- `6. Microservices gRPC` - service-to-service communication with gRPC

## Stack

NestJS, TypeScript, PostgreSQL, Drizzle ORM, Docker, Redis, RabbitMQ, and gRPC.

## Purpose

Use this repo as a step-by-step reference for building modern Node.js backends, from a single modular API to distributed microservice systems. Each folder is a standalone project that you can run and explore. The code emphasizes best practices, clean architecture, and real-world patterns to help you level up your backend development skills.
